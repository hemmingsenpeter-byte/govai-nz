# Code of conduct

Treat contributors respectfully. Critique code and evidence, not people. Harassment, discrimination, threats, doxxing, and unwanted personal contact are not acceptable.

Keep contributions relevant to the project's neutral technical scope. Do not post personal information or exploit details. Maintainers may remove harmful content, restrict participation, or close off-topic discussions, explaining decisions where it is safe to do so.

For private concerns, use an available private maintainer channel; ask for one without naming affected individuals publicly if no channel has been established.
