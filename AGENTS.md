# Agent instructions

Read `CONTRIBUTING.md`, `ARCHITECTURE.md`, `SECURITY.md`, and `ROADMAP.md` before changes. `CONTRIBUTING.md` is canonical for commands and contribution rules.

Implement one agreed task at a time. Do not add live model calls, credentials, domain calculations, or unsupported government-compliance claims. Never bypass a denied/review-required outcome or an audit-write failure. State what passed and what could not be tested. Ask a maintainer before changing public contracts or merging.
