# Declarative policy configuration

**Status:** Planned contribution area; no production implementation yet.

Put classification/provider/review/tool/cost rule data here. YAML examples in this directory are illustrative and are not loaded by the offline demo. services/policy/ implements and validates interpretation. Never silently relax restrictions on invalid configuration.

Before writing files, read the [repository map](../REPOSITORY_MAP.md), CONTRIBUTING.md and this directory's scope. Add implementation-specific commands, contracts and test locations when this module becomes executable.
