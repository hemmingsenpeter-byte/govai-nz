# GovAI-NZ

An unofficial, community-built reference implementation for auditable, vendor-neutral AI systems in New Zealand's public sector.

**Not affiliated with or endorsed by the New Zealand Government or Government Chief Digital Officer.** This is an early engineering demonstrator, not an approved government standard, accredited system, or production security product.

## What is here

This foundation demonstrates a replaceable model-provider interface, explicit public-only policy, human-review escalation, and structured audit events. It runs offline, without credentials or paid model calls. It uses Python's standard library so anyone can inspect and run it.

```bash
python --version  # Python 3.12 or newer
python -m unittest discover -s tests -v
PYTHONPATH=src python -m govai_nz.demo
```

The demo shows an allowed public request, a blocked non-public request, a high-impact request awaiting human review, and a provider failure. Every outcome writes a distinct audit event to a temporary SQLite database. The mock response is synthetic and is not generated by an AI model.

## Scope

Generic infrastructure: model portability, information controls, provenance, human oversight, audit export, and conformance tests. Domain-specific policy calculations, citizen eligibility decisions, political campaigning, economic simulations, and commercial applications belong outside this repository.

Only synthetic or explicitly public input is permitted in this demo. Caller-declared labels are **not** a working information-classification or personal-information detection system. The demo has no authentication, HTTP service, live retrieval, or approval-resume endpoint. Review-required requests stop before provider execution.
